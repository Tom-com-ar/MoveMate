# MoveMate

Aplicación móvil de seguimiento de actividad física construida con React Native, Expo y TypeScript.

## Estado del proyecto

- **M1 - Pantalla de inicio:** completado.
- Dashboard diario con pasos, distancia y calorías.
- Animaciones de entrada escalonadas y barra de progreso animada con Reanimated.
- Diseño adaptable a pantallas Android angostas.

Los valores del dashboard son datos de demostración. Se conectarán a los datos reales de actividad en los requisitos de GPS y persistencia.

## Ejecutar

```bash
npm install
npm start
```

Después, abrí el proyecto con Expo Go o un emulador.

## Verificaciones

```bash
npm run check
```
